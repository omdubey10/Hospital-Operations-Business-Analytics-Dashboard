# Hospital Operations & Business Analytics Dashboard

An end-to-end **Business Data Analyst** portfolio project using **Excel, Python/Pandas, SQL, Power Query and Power BI** to analyze hospital operations, patient activity, appointment performance and billing.

## Business Objective

Analyze hospital data to identify:
- Revenue trends
- Department performance
- Appointment completion/cancellation patterns
- Doctor workload
- Patient waiting time
- Admission and length-of-stay patterns
- Billing data-quality issues

## Tech Stack

| Tool | Purpose |
|---|---|
| Excel | Data validation and quality checks |
| Python / Pandas | Data cleaning and preparation |
| SQL | Business analysis and KPI extraction |
| Power Query | Transformation and data integration |
| Power BI | Dashboarding and visualization |

## How to Run

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd Hospital_Business_Analytics
```

### 2. Install Python dependency

```bash
pip install pandas numpy
```

### 3. Run the cleaning script

```bash
python python/clean_hospital_data.py
```

Cleaned files will be created inside `data/cleaned/`.

### 4. SQL

Load the CSVs into MySQL/PostgreSQL and run:

```text
sql/hospital_analysis.sql
```

### 5. Power BI

Import the cleaned tables and apply the transformation steps in:

```text
powerbi/power_query_steps.md
```

Then create the measures from:

```text
powerbi/dax_measures.md
```

## Important Note

This project uses **synthetic data** for portfolio and learning purposes. It does not contain real patient records or protected health information (PHI).

## Portfolio Positioning

This project demonstrates an end-to-end analytics workflow rather than a dashboard-only exercise. The emphasis is on data quality, reproducible cleaning, SQL-based analysis, business KPIs and decision-oriented visualization.
